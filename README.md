## Problem-Solving Approach

For every problem, I try to follow:

```text
1. Understand the problem
2. Identify constraints
3. Think about possible approaches
4. Choose the data structure / algorithm
5. Implement the solution
6. Test edge cases
7. Analyze time and space complexity
8. Look for possible improvements
```

## Complexity Matters

A solution that works is only the first step.

I also focus on understanding:

```text
Time Complexity
Space Complexity
Scalability
Edge Cases
Readability
```

Common complexity levels:

| Complexity | Meaning      |
| ---------- | ------------ |
| O(1)       | Constant     |
| O(log n)   | Logarithmic  |
| O(n)       | Linear       |
| O(n log n) | Linearithmic |
| O(n²)      | Quadratic    |

## Run the Code

Clone the repository:

```bash
git clone https://github.com/akshatas28/Advance_Python.git
```

Move into the repository:

```bash
cd Advance_Python
```

Run a Python file:

```bash
python filename.py
```

For lecture-based material:

```bash
cd Lecture1
python <filename>.py
```
